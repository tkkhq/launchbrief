# Trellini MCP snapshot

The JavaScript files in this directory are compiled from `../trellini/mcp/src`
at commit `b83bb184d7ca37f7693f55410adf60766d55f73c` with its `npm run build`.
They are kept in LaunchBrief's Functions bundle so Claude Agent SDK can launch
Trellini's existing service-key MCP server over stdio in the deployed runtime.
The Trellini repository is not modified. Update this snapshot when the upstream
MCP contract changes.
